EVENTMATE - EVENT MATERIAL SUPPLY
==================================
Frontend:
Open frontend/index.html in a browser.

Backend:
Requirements: Java 17+ and Maven.
1. Open terminal in backend/
2. Run: mvn spring-boot:run
3. Backend API: http://localhost:8080/api/bookings
4. GET bookings: http://localhost:8080/api/bookings
5. H2 console: http://localhost:8080/h2-console

This starter uses H2 file database. You can later switch to MySQL.
